# Mini CV

Page de CV personnelle en HTML, CSS et sans dépendance.

## Démo

Page en ligne : https://aymanmechal.github.io/mini-cv/

## Aperçu

Une page unique `index.html` avec :
- un en-tête (nom et titre)
- une section « À propos »
- la liste des expériences
- la liste des compétences
- un pied de page avec le contact

## Installation

```bash
git clone https://github.com/aymanmechal/mini-cv.git
cd mini-cv
